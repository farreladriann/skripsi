# References

Folder ini menyimpan metadata, catatan literatur, dan hasil kurasi referensi untuk skripsi RRU.

## Konvensi

- PDF sumber literatur bersifat lokal dan di-ignore oleh Git (`references/*.pdf` dan `references/**/*.pdf`).
- File catatan ringan seperti `.md`, `.json`, `.bib`, dan `.csv` boleh di-track.
- Jika paper dipakai dalam naskah, masukkan metadata sitasinya ke `thesis/references.bib`, bukan mengandalkan PDF di repo.

Dengan aturan ini, repo GitHub tetap ringan dan tidak mengunggah file PDF literatur yang tidak perlu.
