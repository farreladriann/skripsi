# Previous Thesis / Prior Work Notes

Folder ini dipakai untuk menyimpan **catatan pembacaan** skripsi/paper terdahulu yang relevan dengan metodologi MPD/GPS.

## Konvensi

- File PDF sumber bersifat lokal dan di-ignore oleh Git (`previous-thesis/*.pdf`).
- Hasil ekstraksi teks penuh juga lokal dan di-ignore (`previous-thesis/_extracted_text/`).
- Yang aman di-track ke GitHub adalah ringkasan pembacaan `*.reading.md` dan README ini.

Tujuannya agar repo tetap ringan dan tidak mengunggah naskah lengkap pihak lain ke GitHub.
